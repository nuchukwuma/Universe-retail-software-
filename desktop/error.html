HordeDesk could not start

The app could not open the shop's data.

The shop's data is kept in files on this laptop. Try this:

  1. Make sure HordeDesk is not already open in another window (only one can use the data at a time), then press Try again.
  2. Still not working? Restart the laptop and open HordeDesk again.
  3. Check the laptop's disk is not full (File Explorer, This PC).
  4. Otherwise press Open log folder and send hordedesk.log to whoever looks after the app.
