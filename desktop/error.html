Universe POS could not start

The app could not open the shop's database.

Usually this means MongoDB is not running. Try this:

  1. Wait one minute. Just after the laptop is switched on, MongoDB can take a moment to start.
  2. Press Try again.
  3. Still not working? Press the Windows key, type services.msc and press Enter. Find MongoDB Server, right-click it and choose Start.
  4. If MongoDB Server is not in the list, MongoDB is not installed. See the install guide (README).
